## Welcome to Jeeva-Bindu!

**A Rapid Response Blood Donor Directory for Rural Healthcare**

---

## 🎯 What is This?

Jeeva-Bindu is a complete Android application that connects blood donors with hospitals in emergency situations. Built with modern Android technologies, it demonstrates:

- ✅ Real-time emergency alerts (< 5 seconds)
- ✅ Smart donor eligibility tracking (90-day rule)
- ✅ Location-based donor matching
- ✅ Push notifications via Firebase
- ✅ Clean MVVM architecture
- ✅ Jetpack Compose UI

## 🌟 Key Features

### For Users
1. **Register as Donor** - Blood group, location, contact
2. **Post Emergencies** - Hospital needs blood urgently
3. **Receive Alerts** - Instant notifications (< 5 sec)
4. **Respond Quickly** - "I'm Coming" button
5. **Search Donors** - Filter by blood group & location
6. **Track Eligibility** - Automatic 90-day calculation

### For Developers
1. **Modern Stack** - Kotlin, Compose, Firebase
2. **Clean Architecture** - MVVM with repositories
3. **Real-time Data** - Firestore listeners
4. **Push Notifications** - FCM integration
5. **Material 3** - Latest design system
6. **Well Documented** - 60+ pages of docs
